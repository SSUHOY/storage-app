# 📂 Personal Storage & Ableton Archive Hub

Полнофункциональный fullstack пет-проект для локального хранения, организации и управления файлами (фотографиями, Ableton-проектами, архивами) с удобным веб-интерфейсом.

## 🛠 Стек технологий

- **Frontend:** Vue 3 (Composition API, `<script setup>`, Vue Router, Axios)
- **Backend:** Python 3.11, FastAPI, Uvicorn, Python-Multipart
- **Архитектура & Утилиты:** Docker, Docker Compose, детерминированные UUID (`uuid5`) для безопасной идентификации файлов и папок без тяжелых баз данных.

---

## 🚀 Архитектурные особенности

1. **Динамическое создание папок:** Бэкенд использует `os.makedirs(..., exist_ok=True)` для рекурсивного создания директорий на диске при загрузке файлов.
2. **Безопасные ID (UUID5):** Все файлы и папки на фронтенде удаляются по уникальным хэш-идентификаторам, сгенерированным на основе путей. Это полностью решает проблемы со спецсимволами, пробелами и кириллицей в путях (например, с именами треков Ableton).
3. **Рекурсивное удаление:** Удаление папки на сервере стирает всю директорию целиком со всем вложенным содержимым (`shutil.rmtree`).

---

## ⚙️ Быстрый старт (через Docker Compose)

Для запуска проекта на компьютере вам понадобятся установленные **Docker** и **Docker Compose**.

1. Клонируйте репозиторий:
- git clone <ссылка-на-ваш-репозиторий>
- cd my-files-project

2. Сервисы будут доступны по адресам:
- Frontend: http://localhost:3000 (или порт, указанный в вашей конфигурации)
- Backend API & Swagger Docs: http://localhost:8000/docs
